You say to the waiter “Please bring me the item and the price from the menu, only drinks, cheapest first, and just 3 of them. Thank you!”
↓ same thing in SQL
SELECT item, price FROM menu WHERE type = 'drink' ORDER BY price LIMIT 3;
Two new questions

In what order? How many?

Lesson 1 gave you three questions. Today adds two more, each with its own colour.

ORDER BY In what order?
Lines the rows up, like people in a queue

Name the column to sort by, like ORDER BY price. Without it, the order of the rows is not guaranteed.

LIMIT How many?
Keeps only the first few rows

Give a number, like LIMIT 3. You get the first 3 rows and the rest are left behind.

Up or down?

ASC walks up the stairs, DESC walks down

After the column name you can add one small word to choose the direction. Think of a staircase.

ASC
Ascending = going up. Small to big. A to Z. ORDER BY price ASC → £2.50, £3.00, £3.50 …
DESC
Descending = going down. Big to small. Z to A. ORDER BY price DESC → £5.50, £4.50, £4.00 …
Good to know: if you write nothing, SQL walks up. ORDER BY price is the same as ORDER BY price ASC. So you only need to type DESC when you want biggest first.
Sort first, then cut: imagine lining children up from shortest to tallest, then picking the first 3. You get the 3 shortest. That is why ORDER BY always comes before LIMIT. If you cut first, you would get any 3.
The full order, in one sentence

Some Friendly Waiters Offer Lemonade

Now there are five words, and they always go in the same order. The first letter of each word in this sentence gives you the order.

You can skip WHERE, ORDER BY or LIMIT when you don't need them. But the ones you use always stay in this order.

Putting rows in order
ORDER BY“sorted by…”ORDER BY priceTwo words that always go together. Says which column decides the order.
ASC“smallest first”ORDER BY price ASCUp the stairs: small to big, A to Z. This is what you get if you write nothing.
DESC“biggest first”ORDER BY price DESCDown the stairs: big to small, Z to A.
,“then by…”ORDER BY type, priceSort by type first. When two rows have the same type, sort those by price.
Choosing how many
LIMIT“only the first…”LIMIT 3Always the very last word. Keeps that many rows from the top.
3“three”LIMIT 3A whole number with no quotes, because it is a number, not text.
The comma changes its job depending on where it is. After SELECT it means “and”: SELECT item, price shows item and price. After ORDER BY it means “then by”: ORDER BY type, price sorts by type, then by price when the types are the same.
How text is sorted: like a dictionary, A to Z. Numbers are sorted by size, so 9 comes before 10.
