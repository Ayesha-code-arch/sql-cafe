In Lesson 3 the receipt words squashed the whole menu into one answer. But what if you want one answer for the drinks and another for the food? Today you learn to put the rows into piles first, then get one answer per pile.

You say to the waiter “Please could you tell me the average price for each type: one for the drinks and one for the food? Thank you!”
↓ same thing in SQL
SELECT type, AVG(price) FROM menu GROUP BY type;
The one thing to remember

Make piles, then squash each pile

GROUP BY works like a waiter putting the menu cards into piles: all the drinks in one pile, all the food in another. Then the receipt words squash each pile into one row. So you get one row per pile.

Compare with Lesson 3: without GROUP BY, all the rows left after WHERE make one big pile, so you get one row. With GROUP BY type, there are two piles, so you get two rows. One pile in, one row out, for every pile.
About the numbers: the drinks add up to £14.50, and £14.50 ÷ 4 = £3.625, shown here rounded to £3.63. The food adds up to £16.00, and £16.00 ÷ 4 = £4.00.
The pile rule

Pile label, or inside brackets

Every column after SELECT must be either the pile label (a column named in GROUP BY) or inside a receipt word.
✓
SELECT type, COUNT(*) FROM menu GROUP BY type

type is the pile label, and COUNT(*) is inside brackets. Every pile can show both.

✗
SELECT type, item, COUNT(*) FROM menu GROUP BY type

The drinks pile has four different items. Which one should its single row show? There is no right answer, so most databases give an error.

✓
SELECT type, MIN(item) FROM menu GROUP BY type

Putting item inside a receipt word fixes it: “the first item from A to Z in each pile”.

A second new word

WHERE picks rows, HAVING picks piles

Sometimes you only want some of the piles, for example “only the types that cost more than £3.80 on average”. WHERE can't do this, because WHERE checks one row at a time, before any piles exist. That is what HAVING is for.

WHERE Which rows? Before the piles are made WHERE calories < 200

Throws away single rows. Receipt words are not allowed here.

HAVING Which piles? After each pile is squashed HAVING AVG(price) > 3.8

Throws away whole piles. Here only food is kept, because its average is £4.00 and the drinks average is £3.625.
